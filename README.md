## Featured project · FlowStock

**An inventory and order management project built with .NET 10.**

FlowStock is my ongoing engineering lab: a place to turn architecture concepts into working software, make design decisions, and learn from implementation.

| Area | Current work |
| :--- | :--- |
| Service boundaries | Separate UserManagement and Stock services, each with its own PostgreSQL database |
| Application design | Clean Architecture, DDD concepts, CQRS, and MediatR |
| Authentication | Registration, login, JWT authentication, and permission-based authorization |
| Catalog | Product category CRUD and ongoing product domain development |
| Observability | Structured logging with Serilog and Seq; tracing with OpenTelemetry and Jaeger; metrics with Prometheus and Grafana |
| Quality & workflow | xUnit and Moq tests, GitHub Actions CI, and Docker Compose for local infrastructure |

**Next areas of work:** inventory reservations, order workflows, RabbitMQ messaging, and service containerization.
